# SimpMusic Android TV — P1B fixes and P2 visual/production plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the P1B remote-control gaps, then give the TV app a TV-native identity, a cinematic
player, consistent secondary screens and a production finish.

**Architecture:** Everything is gated on `LocalTvDevice` and lives in shared `composeApp` code:
- design tokens, focus styles, motion and materials sit in `ui/tv/`;
- existing screens consume them through small, gated branches;
- the logic that can be pure (scroll keylines, contrast, the overlay state machine, scrub
  acceleration, lyric windows, motion resolution) is pure Kotlin with jvmTest coverage;
- the visual result is checked on the owner's TV by screenshots that are never committed.

**Tech Stack:**
- Kotlin, Compose Multiplatform (material3-multiplatform 1.12.0-alpha03), Coil 3, Koin;
- Kyant backdrop (Liquid Glass) only where API ≥ 31;
- kotlin.test in `composeApp/src/jvmTest`;
- the Python TV tools in `tools/`.

**Spec:** `docs/superpowers/specs/2026-11-10-tv-p2-visual-design.md`. Read it before any task. All
token values below come from it.

## Global Constraints

- **Gating.** Every behavior or visual change is gated on `LocalTvDevice.current`, so phone,
  tablet and desktop output stays the same. Shared helpers return the input unchanged off TV,
  like `ui/tv/TvInput.kt` does.
- **Untouched areas.** No changes to AutoMix, crossfade, EQ, audio effects, queue logic or
  `core/`, unless a task states the justification.
- **No rewrites.** Adapt the existing screens. New TV components are allowed for chrome (rail,
  side panel, player layout), and must reuse the existing view models and data.
- **Signing and install.** Every APK installed on the TV is signed with the owner's keystore
  through `tools/tv_install.py --release`. Never pass `--uninstall-first`. Never uninstall
  `com.maxrave.simpmusic.dev` or `com.maxrave.simpmusic.tv`, whose data holds the owner's
  signed-in account.
- **Nothing private in git.** Never commit or attach screenshots, logs, traces, IPs, account
  names, cookies or `secrets.env`. The `shots/`, `smoke/` and `work/` folders are gitignored.
- **Logging.** Keep debug logging as upstream has it; do not suppress logs.
- **Builds.** Per the repo's CLAUDE.md, do not run Gradle builds just to check edits. The gates
  are:
  - `./gradlew :composeApp:jvmTest --tests "com.maxrave.simpmusic.ui.tv.*"` (plus the named
    player tests);
  - `./gradlew :composeApp:compileKotlinJvm`;
  - one `tools/tv_install.py --release` per task that ends in a TV check, which the owner
    requested.

  On Windows, set `JAVA_HOME="/c/Program Files/Android/Android Studio/jbr"`.
- **TV access.** The TV is on the owner's LAN, with its address in `TV_HOST` from the local
  environment. This plan runs in a local terminal with ADB access.
  - A session that cannot reach the TV still runs the jvmTest and compile gates, but must record
    every "TV check" as **pending** in its PR.
  - No aesthetic PR counts as visually done without real TV screenshots and a D-pad focus pass.
- **Device settings.** Any step that changes a device setting (`animator_duration_scale`,
  `font_scale`, the screensaver timeout) must:
  - read and save the original value first;
  - restore that exact value afterwards, in a `try/finally` or equivalent, including when the
    check fails;
  - never restore a fixed value such as 1.
- **TV tooling quirks:**
  - `tools/tv.py --screenshot <png> KEYS --wait N` sends keys.
  - Without `--screenshot`, the arguments run as one shell command and no keys are sent.
  - Each call reconnects in 1–2 s, so the player's 5 s overlay timeout can expire between calls.
    Batch keys and the screenshot in one call.
- **Icons** come only from `SimpIcons` (see CLAUDE.md "Add a New Icon"); never add
  material-icons.
- **Strings.** New user-visible strings go in `composeResources` `values/strings.xml`, with
  `values-vi` and `values-pt-rBR` translations added in the same commit (check that the folder
  names exist).
- **Commits** use conventional types (`feat(tv):`, `fix(tv):`, `docs(tv):`) and end with
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **PRs:**
  - Bodies end with `🤖 Generated with [Claude Code](https://claude.com/claude-code)`.
  - Never merge.
  - Each phase is one PR, stacked on the previous phase's branch: P1B on
    `codex/tv-native-shell`, then P2-A on P1B, P2-B on P2-A, P2-C on P2-B and P2-D on P2-C.
  - Report the branch, head SHA and PR URL.
- **Owner's taste** (memory `feedback-tv-ui-aesthetics`):
  - no outline focus rings;
  - nothing that looks like a phone or tablet layout;
  - Spotify TV is the reference;
  - the owner judges looks even in functional phases, so every TV check step ends with
    screenshots shown to the owner.

## Review Focus

1. **Holding a D-pad key** (about 20 repeats/s) across a row or the rail must not queue
   animations, must not reload the immersive header on every card, and must never move focus
   into hidden overlay controls.
   - Tests: `tvKeylineScrollDeltaIsIdempotentAtKeyline` (Task 3) and
     `headerDebounceIgnoresTransientFocus` (Task 6).
   - TV check: hold RIGHT for 3 s on Home in Task 6, and scrub tests `scrubIgnoresRepeatRate` (Task 7).
2. **Missing or failed artwork** (null URL, a 404, a video with no thumbnail) must fall back to
   `background` and to an empty glow. There must be no black hole, no crash, and no stale
   artwork from the previous track.
   - Test: `ambientModelIsNullForBlankUrl` (Task 4).
   - TV check: a track with no artwork in Task 8.
3. **Track change, end of queue, and switching between audio and video while the player is
   open.** The overlay state, the lyric window and the artwork transition must reset correctly.
   - Tests: `trackChangeKeepsOverlayVisibilityAndResetsTimer`,
     `endedShowsOverlayAndStopsTimer` (Task 7) and `windowClampsAtEnds` (Task 8).
4. **Animator scale 0** (common on TVs) or reduced motion: no infinite drift, no springs, and
   feedback still visible.
   - Tests: `zeroAnimatorScaleSelectsReducedMotion` (Task 2) and
     `reducedMotionDisablesDrift` (Task 8).
5. **Long and non-Latin titles** (CJK, Vietnamese diacritics, RTL) in the chip, cards, header
   and player at 1.10 focus scale: ellipsis, no clipping by a parent, and no overlap with the
   next card.
   - TV check: a Vietnamese/CJK track in Tasks 6 and 8.
   - Test: `cardFocusScaleFitsGutter` (Task 1) asserts that the scaled card's growth fits inside
     the 20 dp gap.
